BEHIND THE CONNECTION

One flow. Three roles.

  1. 01
    This application

    The OAuth client requests permission to read your file metadata.

  2. 02
    Google authorization

    You grant access. The server exchanges the code for an access token.

  3. 03
    Google Drive API

    The resource service returns files when presented with a valid bearer token.

REQUESTED SCOPE

drive.metadata.readonly

View file names, types, and dates. File contents cannot be read or changed with this scope.
